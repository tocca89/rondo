# Changelog

## 1.3.0
- One-click updates: "Install and Relaunch" downloads the new version, checks its Ed25519 signature, replaces the app (the old copy goes to the Trash) and relaunches. Falls back to the manual DMG if Rondo can't update itself.

## 1.2.0
- Guided ffmpeg setup: without ffmpeg, audio/video wheels show a "More Formats…" slice that installs it with Homebrew, or downloads a static Apple-silicon build (SHA-256 verified) into Rondo's own folder.

## 1.1.0
- Update checks: Rondo looks for new releases on GitHub once a day (can be turned off in Settings) and offers to download them.
- "Check for Updates…" in the menu bar and in Settings.
- New "About Rondo" window with version, links to the source code and to the author.

## 1.0.0
- First public release.
- Radial wheels while dragging: ⇧ Convert, ⌘ Tools, ⌃ Actions (keys configurable).
- Images, audio, video, PDF, documents, tables, subtitles and archives — all processed locally.
- Animated wheel, progress ring in the HUD and menu bar, interactive onboarding.
- English, Italian, Spanish, French, German and Portuguese.
